# AcaDesk - Student Risk Prediction System

##  Overview
AcaDesk is a Machine Learning-based system designed to identify students who are at academic risk.  
The system analyzes student data such as attendance, academic performance, and engagement to predict risk levels and enable early intervention.

This project aims to support educational institutions in making data-driven decisions to improve student outcomes.

---

##  Problem Statement
Identifying at-risk students manually is inefficient and often inaccurate. Institutions need an automated system to detect risk early and take preventive actions.

---

##  Features
- Predicts student academic risk levels
- Uses machine learning for classification
- Analyzes structured student data
- Helps in early intervention
- Scalable and modular design
